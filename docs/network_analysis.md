# Drosophila-NeuroAtlas — Phase 6: Network Analysis Engine Specification

## 1. Overview and Objective

The Network Analysis Engine (Phase 6) operates on bounded connectome subgraphs and discrete-time simulation trajectories generated by Phase 5. It quantifies graph topology, target-centered reachability, centrality measures, and perturbation-induced state shifts.

```
CONNECTOME SUBGRAPH
        +
SIMULATION RESULT (Phase 5)
        ↓
NETWORK ANALYSIS ENGINE (Phase 6)
        ↓
STRUCTURAL METRICS + CENTRALITY + REACHABILITY + DYNAMIC METRICS
        ↓
INTERPRETABLE, TYPED RESULTS
```

---

## 2. Core Scientific Principles and Boundaries

### 2.1 Structural vs Simulation-Derived Metrics
The engine strictly distinguishes:
- **Structural Metrics**: Topological properties computed directly from the directed connectome graph (e.g., node count, degree distribution, density, components, graph distance).
- **Simulation-Derived Metrics**: Dynamic properties computed from modeled simulation histories (e.g., baseline vs. perturbed state deltas, peak change times, area under the modeled activity curve).

### 2.2 Strict Terminology Boundaries
> **GOLDEN RULE**: Network metrics describe the analyzed computational graph and should not automatically be interpreted as measurements of biological importance or causal influence.

| Computational Metric / Term | Permitted Interpretation | Prohibited Claims |
|---|---|---|
| **Modeled Activity ($a$)** | Discrete numerical state variable in $[0.0, 1.0]$ | Action potential firing rate, EPSP amplitude |
| **Model-Affected Neuron** | Neuron where $\| \Delta a \| \ge \theta$ (computational threshold) | Biologically poisoned, toxicologically vulnerable |
| **Betweenness / Degree Centrality** | High modeled network centrality in analyzed subgraph | "Biologically critical neuron", "master control node" |
| **Reachability** | Directed path existence in the extracted subgraph | In vivo synaptic transmission, behavioral circuit trigger |
| **Delta Total Activity ($\Delta A_{\text{total}}$)** | Sum of computational state shifts across nodes | Global neurotoxic severity |

## 3. Mathematical Definitions

### 3.1 Structural Graph Metrics
Let $G = (V, E)$ be a directed connectome subgraph with $|V| = N$ neurons and $|E| = M$ directed connections.

1. **Graph Density**:
   $$\text{Density} = \frac{M}{N(N - 1)} \quad \text{for } N \ge 2, \quad \text{else } 0$$
   Bounded strictly in $[0, 1]$.
2. **In-Degree and Out-Degree**:
   $$\text{deg}_{\text{in}}(v) = |\{ u \in V : (u, v) \in E \}|, \quad \text{deg}_{\text{out}}(v) = |\{ w \in V : (v, w) \in E \}|$$
3. **Connected Components**:
   - **Weakly Connected Components (WCC)**: Components when edge direction is ignored.
   - **Strongly Connected Components (SCC)**: Subgraphs where every vertex is reachable from every other vertex following directed edges.
4. **Average Directed Shortest Path Length**:
   $$\langle L \rangle = \frac{1}{\sum_{u \ne v} \mathbf{1}_{\exists \text{path}(u, v)}} \sum_{u \ne v, \exists \text{path}(u, v)} d(u, v)$$
   Calculated across all ordered pairs $(u, v)$ with existing directed paths. If no paths exist or $N < 2$, $\langle L \rangle = \text{None}$.

### 3.2 Modeled Centrality Metrics
1. **In-Degree Centrality**:
   $$C_{\text{in}}(v) = \frac{\text{deg}_{\text{in}}(v)}{N - 1}$$
2. **Out-Degree Centrality**:
   $$C_{\text{out}}(v) = \frac{\text{deg}_{\text{out}}(v)}{N - 1}$$
3. **Directed Betweenness Centrality**:
   $$C_B(v) = \sum_{s \ne v \ne t} \frac{\sigma_{st}(v)}{\sigma_{st}}$$
   where $\sigma_{st}$ is the total number of directed shortest paths from $s$ to $t$ and $\sigma_{st}(v)$ is the number of those paths passing through $v$.
4. **Directed Closeness Centrality**:
   $$C_C(v) = \frac{n - 1}{\sum_{u \ne v} d(u, v)}$$
   for nodes reachable to $v$ in directed paths.

### 3.3 Target-Centered Reachability
For each perturbation target $T$:
- **Upstream Pre-synaptic Partners**: $\text{Pred}(T) = \{ u \in V : (u, T) \in E \}$
- **Downstream Post-synaptic Partners**: $\text{Succ}(T) = \{ w \in V : (T, w) \in E \}$
- **$k$-Hop Downstream Reachability**:
  $$R_k(T) = \{ v \in V : d(T, v) = k \}$$
  computed using breadth-first search cutoff at $\text{max\_hops}$.

### 3.4 Dynamic Perturbation Metrics
For each neuron $v \in V$:
- **Delta Activity**:
  $$\Delta a(v) = a_{\text{perturbed}}(v, t_{\text{final}}) - a_{\text{baseline}}(v, t_{\text{final}})$$
- **Absolute Delta**:
  $$\| \Delta a(v) \| = | \Delta a(v) |$$
- **Model-Affected Classification**:
  A neuron is classified as model-affected if:
  $$\| \Delta a(v) \| \ge \theta$$
  where $\theta$ is the user-configured computational threshold (default: $0.05$).
- **Network-Level Metrics**:
  - Total activity shift: $\Delta A_{\text{total}} = \sum_{v \in V} a_{\text{perturbed}}(v) - \sum_{v \in V} a_{\text{baseline}}(v)$
  - Mean absolute activity change: $\langle \| \Delta a \| \rangle = \frac{1}{N} \sum_{v \in V} \| \Delta a(v) \|$
  - Model-affected fraction: $f_{\text{affected}} = \frac{N_{\text{affected}}}{N}$

### 3.5 Temporal Metrics
Computed across discrete simulation timestamps $t_0, t_1, \dots, t_K$:
- **Peak Absolute Change**:
  $$\| \Delta a \|_{\text{peak}} = \max_{k} | a_{\text{perturbed}}(v, t_k) - a_{\text{baseline}}(v, t_k) |$$
- **Time of Peak Change**:
  $$t_{\text{peak}} = \arg\max_{t_k} | a_{\text{perturbed}}(v, t_k) - a_{\text{baseline}}(v, t_k) |$$
- **Area Under Modeled Curve (AUC)** via Trapezoidal Rule:
  $$\text{AUC}(v) = \sum_{k=0}^{K-1} \frac{a_{\text{perturbed}}(v, t_k) + a_{\text{perturbed}}(v, t_{k+1})}{2} (t_{k+1} - t_k)$$
- **Time to Threshold**: First timestamp $t_k$ such that $| a_{\text{perturbed}}(v, t_k) - a_{\text{baseline}}(v, t_k) | \ge \theta$.

## 4. Engineering Limits and Safeguards

To ensure real-time responsiveness and protect server memory, the analysis engine enforces hard bounded limits:
- `MAX_ANALYSIS_NODES = 500`: Graphs exceeding 500 nodes are rejected with a clear 400 validation error.
- `MAX_ANALYSIS_EDGES = 5000`: Subgraphs with more than 5000 connections are rejected.
- `MAX_PATH_LENGTH = 10`: Reachability searches are capped at 10 hops.

## 5. API Endpoints

- `POST /analysis/network`:
  ```json
  {
    "simulation_id": "sim_abc123",
    "threshold": 0.05,
    "max_hops": 3
  }
  ```
  Returns `NetworkAnalysisResult` containing structural metrics, centralities, target reachability, perturbation dynamic summary, and provenance.
- `GET /analysis/network/{simulation_id}?threshold=0.05&max_hops=3`:
  Convenience query endpoint.
